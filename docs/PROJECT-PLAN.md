# 사례 B: VIP 프리뷰에서 재방문까지

[프로젝트 소개로 돌아가기](../README.md)

## 향 브랜드 신제품 프리뷰를 가정한 고객 생애주기 운영안

공개 자료와 가상 데이터로 작성한 개인 포트폴리오입니다.

CRM은 동의한 고객의 선택과 반응 기록을, LOOP는 그 기록이 초청, 참석, 상담, 재방문으로 다시 이어지는 순환을 뜻합니다. 연락은 마케팅 수신에 동의한 고객에게만 보낸다는 조건을 두었습니다.

CRM LOOP는 제가 붙인 프로젝트 이름입니다. 공개 자료를 참고한 브랜드가 실제로 사용한 행사명은 아닙니다.

현장에서 확인한 향 선택을 고객의 동의 아래 상담, 예약과 재방문 기록으로 연결했습니다.

- 기간: 가상 일정 / T-8주부터 행사 후 30일까지
- 장소: 서울 성수 / 실제 공간 계약 전 가정
- 목표: VIP 프리뷰에서 확인한 향 선호와 상담 요청을 놓치지 않고, 동의한 고객에게 필요한 후속 안내를 보내는 흐름을 정리했습니다.
- 메시지: 차 안의 기억을 향으로 설계하고, 현장의 발견을 다음 경험으로 이어갑니다.

## 고객군

### VIP_REPEAT / 기존 우수, 재구매 고객
- 가상 초청: 70명
- 선정 이유: 기존 향 구매와 재구매 관계를 바탕으로 신제품 적합성을 확인
- 제공 가치: 선호 향 기반 프리뷰와 리필 케어
- 다음 행동: 구매 여부에 따라 사용 팁, 리필 시점 안내

### HIGH_INTENT / 고관여 잠재 고객
- 가상 초청: 80명
- 선정 이유: 카디퓨저, 자동차 라이프스타일 콘텐츠에 반응한 고객 가정
- 제공 가치: 향 비교와 차량 환경별 상담
- 다음 행동: 상담 요청, 예약, 미구매 이유별 후속

### CREATOR / 콘텐츠 크리에이터
- 가상 초청: 30명
- 선정 이유: 브랜드 적합성, 콘텐츠 품질, 공개 범위를 사전 검토한 대상
- 제공 가치: 공개 전 세계관 프리뷰와 정확한 제품 자료
- 다음 행동: 엠바고, 표기 확인과 콘텐츠 반응 기록

### DORMANT_VIP / 휴면 VIP
- 가상 초청: 60명
- 선정 이유: 과거 구매 이후 일정 기간 관계 신호가 없다는 가정
- 제공 가치: 재활성화를 위한 부담 없는 체험 예약
- 다음 행동: 반응이 없으면 반복 발송을 중지하고 선호 갱신 기회 제공

## 가상 결과 퍼널

- 초청: 240명 / 분모 선정 고객 / 중복 제거, 초청 이유, 담당자 확인 후 발송
- RSVP 응답: 156명 / 분모 초청 240명 / 응답/거절/미응답을 분리
- 방문 확정: 132명 / 분모 응답 156명 / 시간, 동반, 접근성 요청 확인
- 실제 참석: 116명 / 분모 확정 132명 / 체크인 시각으로만 참석 처리
- 체험 완료: 104명 / 분모 참석 116명 / 향 비교 또는 대체 경험 완료
- 마케팅 동의: 82명 / 분모 참석 116명 / 행사 참여와 별도 선택
- 후속 반응: 47명 / 분모 동의 82명 / 열람이 아닌 클릭, 회신, 상담 행동
- 유효 관계 행동: 28명 / 분모 동의 82명 / 상담 12, 예약 9, 구매 7 가정

## 단계 사이 누락 관리

- 초청 → RSVP: 84명 / 48시간 뒤 1회 리마인드. 이후 미응답 종료 / 담당 Local CRM
- 응답 → 확정: 24명 / 거절과 시간 미정 구분, 대기 명단과 대체 시간 안내 / 담당 Guest Manager
- 확정 → 참석: 16명 / 노쇼를 실패로 단정하지 않고 운영 연락 범위에서 사유 선택 수집 / 담당 Guest Manager
- 참석 → 체험 완료: 12명 / DIY 마감, 대기, 시간 부족 사유를 기록하고 대체 샘플 또는 재예약 제공 / 담당 Experience Lead
- 참석 → 동의: 34명 / 거절/미확인을 분리하고 마케팅 후속에서 제외 / 담당 CRM & Privacy
- 동의 → 후속 반응: 35명 / 선호 채널로 최대 2회, 반응 없으면 휴면 처리 / 담당 Lifecycle CRM
- 후속 반응 → 관계 행동: 19명 / 구매 압박 없이 정보 탐색, 상담 보류, 재고 요청으로 분류 / 담당 Client Care

## KPI

- 초청 응답률: 65% (가상 목표 60%) / RSVP 응답 156 ÷ 초청 240 / 타깃과 초청 가치의 적합성
- 참석률: 87.9% (가상 목표 85%) / 실제 참석 116 ÷ 방문 확정 132 / 예약, 리마인드, 접근 안내의 실행력
- 체험 완료율: 89.7% (가상 목표 88%) / 체험 완료 104 ÷ 실제 참석 116 / 대기, 수용량, 대체 경험의 품질
- 마케팅 동의율: 70.7% (가상 목표 65%) / 동의 82 ÷ 실제 참석 116 / 혜택 설명과 선택권의 신뢰
- 후속 반응률: 57.3% (가상 목표 45%) / 반응 47 ÷ 동의 82 / 개인화와 채널, 시점의 적합성
- 관계 행동률: 34.1% (가상 목표 30%) / 상담/예약/구매 28 ÷ 동의 82 / 행사 이후 고객 관계의 사업 연결

## 일정과 산출물

- T-8~6주: 목표, 세그먼트, 시장, KPI, 동의 기준 확정 / CRM 브리프 / 고객 선정 규칙 / 측정 정의
- T-5~3주: 초청 여정, 현지 언어, RSVP, 혜택 재고 설계 / 초청물 / 응답 대시보드 / 대기 명단
- T-2~1주: 고객 명단 점검, 직원 교육, 예외 상황 리허설 / 큐시트 / 담당자표 / 서비스 복구 기준
- D-day: 체크인, 체험 신호, 동의, 상담 요청 실시간 인계 / 현장 로그 / 미처리 고객/업무 목록
- D+1~7일: 선호, 체험, 구매 여부별 후속과 요청 마감 / 후속 캠페인 / 상담/예약 인계
- D+30: 재방문, 구매, 수신 거절, 표본 한계 회고 / 성과 보고 / 다음 시장 테스트안

## 위험 대응

- DIY 또는 예약 혜택 소진: 대체 샘플, 재예약 중 고객 선택 / 대체안 수락률, 7일 반응
- 대기 목표 초과: 도착 분산, 예상 대기 고지, 담당자 호출 / 평균/최대 대기, 조기 퇴장
- VIP 정보 노출 위험: 실명 대신 현장 식별명, 최소 권한과 촬영 동의 분리 / 접근 기록, 동의 누락 0건
- 마케팅 동의 거절: 체험과 기프트는 유지하고 후속 발송 제외 / 잘못된 발송 0건
- 국가별 메시지 불일치: HQ 핵심 문장 고정, 현지 문안, 규정은 Local 승인 / 승인 이력, 수정 건수

- 후속 메시지는 무엇을 기억시켜야 하는가? A=제품 기능 중심, B=고객이 고른 향, 사용 장면 중심 / 클릭, 상담, 예약

## 자료를 확인한 범위

- 젠틀몬스터, 탬버린즈, 누데이크, 어티슈, 누플랏의 공식 채널을 먼저 확인하고, 기사, 공개 방문 자료를 따로 읽었습니다. 독립 방문 후기가 없는 어티슈와 팝업 사례가 아닌 누플랏은 그 한계를 그대로 적었습니다.
- 모든 관련 글을 수집했다고 주장하지 않습니다. 대표 기획안에 직접 필요한 자료를 선별했고, 실제 고객 수, 매출, 초청 기준, 내부 시스템은 확인하지 못했습니다.
- 전체 링크와 자료별 사용 범위는 `RESEARCH-SOURCES.md`와 Excel의 `근거 및 출처` 시트에 정리했습니다.

## 제가 확인하고 정한 것

- CRM 행사 업무를 고객 선정, 현장 경험, 후속 CRM, 결과 확인으로 나눴습니다.
- 다섯 브랜드의 공식 자료와 공개 방문 후기를 따로 읽고, 제가 직접 확인하지 못한 내용은 가정으로 표시했습니다.
- 대기, 품절, 체험 마감 사례를 현장 기록 항목과 후속 업무에 반영했습니다.
- 전환율이 좋아 보이게 분모를 바꾸지 않도록 초청부터 30일 후 행동까지 계산 기준을 먼저 정했습니다.
- 장소와 날씨를 함께 볼 수 있도록 서울시 공공데이터와 Open-Meteo를 웹 화면에 연결했습니다.

## 이 프로젝트를 만든 이유

실제 VIP 행사를 운영한 경험은 없습니다. 그래서 브랜드 공식 자료를 읽고, 공개 후기에서 확인한 대기, 품절과 체험 마감 사례를 운영표의 확인 항목으로 옮겼습니다. 후기 한 건을 전체 고객의 문제로 확대하지 않았고, 고객 수와 전환율은 계산용 가상값으로 표시했습니다. 실제로 적용한다면 고객 기준과 시장별 규정을 먼저 확인하고, 작은 행사 한 건에서 선정, 체험, 동의와 후속 기록을 실제 데이터로 검증해야 합니다.

## 읽기 전에

모든 고객 수와 전환 결과는 계산 구조를 보여주기 위한 가상 데이터입니다. 실제 브랜드의 고객, 매출, 행사 성과가 아닙니다. 공개 방문 후기는 제한된 개인 표본이며 전체 고객 경험으로 일반화하지 않습니다.
