# 문서 안내

CRM LOOP의 기획서, 기획 근거, 실행 문서를 한곳에 모았습니다. 처음 읽는 경우에는 아래 순서를 권합니다.

**캠페인 기획서**

1. [재방문 캠페인 기획서](CAMPAIGN-BRIEF.md)와 [Journey 설계도](JOURNEY.md)에서 이탈 위험 고객에게 무엇을, 언제 보내고 그 판단을 어떻게 확인하는지 봅니다.
2. [VIP 행사 기획안](PROJECT-PLAN.md)(사례 B)에서 행사 목표, 초청 대상과 기준, 경험 설계, 후속 메시지, 성과 기준을 봅니다. 담당자 인계와 일정은 같은 문서의 실행 부록에 있습니다.
3. [비수기 캠페인 기획안](CASE-C-SEASONAL-STAY.md)(사례 C)에서 캠페인 구조, 고객군, 할인 제안과 비교하는 세 군 실험 설계를 봅니다.

**기획 근거**

4. [사례 A 캠페인 측정](CAMPAIGN-MEASUREMENT.md)에서 공개 이메일 실험으로 메일마다 받을 고객을 골라야 하는지 확인한 결과를 봅니다. 점수 모델과 민감도 표 같은 분석 세부 사항도 이 문서에 있습니다.
5. [고객 가치 분석](CUSTOMER-VALUE.md)에서 실제 거래 기록으로 본 이탈 시점, 고객군별 다음 해 재구매, 매출 예측 모델 비교를 봅니다.

**공통 기준과 그 밖의 문서**

6. [KPI 정의서](KPI.md)에서 세 기획서가 함께 쓰는 지표의 분자, 분모, 기간을 확인합니다.
7. [사례 B 조사 자료](RESEARCH-SOURCES.md)와 [기획 판단과 검증 과제](PROJECT-NOTES.md)에서 공개 자료의 출처, 사용 범위와 아직 확인하지 못한 조건을 확인합니다.
8. [제품 기획서](PRD.md)에서 프로젝트 전체의 문제, 범위, 일정과 완료 기준을 확인합니다.
9. 로컬 실행이나 데이터 연결이 필요할 때만 [실행 안내](RUNNING.md)를 확인합니다.

재방문 캠페인은 공개 거래 기록을 근거로 한 기획이고, 사례 B는 가상 행사와 공개 조사 자료를 바탕으로 한 기획이며, 사례 C는 가상 숙박 브랜드의 캠페인 기획과 실험 설계입니다. 사례 A는 공개 실험 데이터 분석, 고객 가치 분석은 공개 거래 기록 분석입니다. 실제 고객 명단, 회사의 캠페인 성과와 내부 운영 기준은 포함하지 않습니다.
